# 🚀 DSA College with JAVA

A structured and comprehensive collection of Java programs, foundational concepts, and Data Structures & Algorithms (DSA) prepared for college curriculum, coding interviews, and competitive programming.

## 📚 Curriculum & Topics Covered

### 1. ☕ Java Fundamentals
- **Syntax & Structure**: Class structure, `main` method, and basic console output.
- **Data Types & Variables**: Integers, floating-point numbers, characters, booleans, and variable scoping.
- **Type Conversion**: Implicit and explicit type casting.
- **Console I/O**: Reading user inputs using `java.util.Scanner`.
- **Operators**: Comprehensive exploration of arithmetic, assignment, relational, logical, and bitwise operators.

### 2. 🔀 Decision Making & Control Flow
- Simple `if-else` and `else-if` ladders.
- Nested conditional constructs.
- Real-world decision logic (Grading systems, Voting eligibility).

### 3. 🔁 Loops & Iterative Algorithms
- `while`, `for`, and nested loop constructs.
- Digit manipulation algorithms (Number reversal, digit summation).
- Stream processing (handling user input until a termination condition).

### 4. 🎨 Pattern Printing
- Logic building using nested coordinate systems `(i, j)`.
- Solid and hollow rectangular shapes.

## 🛠️ Getting Started

### Prerequisites
Make sure you have the Java Development Kit (JDK 8 or newer) installed on your system.

```bash
javac -version
java -version
```

### Compiling & Running Programs

1. **Clone the repository:**
   ```bash
   git clone https://github.com/atul-techx/DSA-College-with-JAVA.git
   cd DSA-College-with-JAVA
   ```

2. **Run a program from the `JAVA` folder:**
   ```bash
   javac JAVA/Hello.java
   java -cp JAVA Hello
   ```

3. **Run a program from the `Pattern` folder:**
   ```bash
   javac Pattern/Hollowrec.java
   java -cp Pattern Hollowrec
   ```
